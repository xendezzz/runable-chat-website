# Cloud backgrounds

Five variations generated with the built-in image tool, using the original hero cloud image as reference. The foreground is live HTML/CSS UI, not generated imagery.

## multimodal

Asset: `dist/assets/feature-cloud-multimodal.png`

Create a new variation of the attached cloud background. Match the reference extremely closely in photographic cloud texture, pastel lavender sky, creamy pale golden sunlit edges, blush pink and subtle mint shadows. Only change the formation/placement of the clouds. No objects, no icons, no scenery, no text, no illustrations or 3D items. Background only. Landscape1536x1024. Keep center spacious for overlay UI. Fluffy clouds gather along the lower left and bottom with a little bank at lower right, open sky across center and top.
